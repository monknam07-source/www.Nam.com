# www.Nam.com — Software Developer Portfolio

Personal portfolio website for **Khairul Anuar bin Sulaiman** — software developer & electronics technician from Malaysia.

## 🌐 Live Site
[www.Nam.com](https://www.nam.com)

## ✨ Features
- **Responsive design** — works on all screen sizes (mobile, tablet, desktop)
- **Dark / Light theme** toggle with `localStorage` persistence
- **Animated hero** with typewriter effect and particle background
- **Scroll-reveal animations** using `IntersectionObserver`
- **Animated skill bars** and counter stats
- **Project gallery** with category filter (Web / Mobile / Hardware)
- **Timeline-style** experience & education section
- **Contact form** with client-side validation (ready for EmailJS / Formspree)
- **Accessible** — semantic HTML5, ARIA labels, keyboard-navigable
- Zero external build tools — pure HTML + CSS + JavaScript

## 🚀 Getting Started
No build step required. Simply open `index.html` in a browser:

```bash
# Clone
git clone https://github.com/monknam07-source/www.Nam.com.git
cd www.Nam.com

# Open in browser
open index.html           # macOS
start index.html          # Windows
xdg-open index.html       # Linux
```

Or deploy to any static host (GitHub Pages, Netlify, Vercel, etc.).
